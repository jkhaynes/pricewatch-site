pricewatch

A Go CLI that prices a Pokémon collection on a free API budget of 1,000 requests a day. It runs every hour on GitHub Actions and never guesses which print a card is.

TropiusNormal
TropiusRev. Holo

Same card number, two prices. Tropius 001/084 is $0.06 as a Normal print and $0.20 as a Reverse Holo. On chase cards the gap between prints dwarfs any price movement, so a card whose print can't be pinned down is left out rather than priced as the wrong one.
